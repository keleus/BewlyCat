# Bilibili 分享海报视觉设计

## 选择方向

采用深色内容卡：以简洁、现代的分享资产为目标，使用深灰到黑色渐变、轻微确定性噪点和高对比白色信息层级。海报优先服务于“确认内容并快速分享”，不重复堆叠品牌装饰。

## 视觉层级

1. 画布使用深灰到黑色渐变，并叠加低密度噪点；背景不再根据封面颜色变化。
2. 顶部直接进入最多两行视频标题，移除左上角重复的品牌文字和青色短线，保留足够的安全边距。
3. 中部放置固定比例的圆角封面，使用统一的黑色压暗层和底部渐变；封面读取失败时使用深色降级面板和本地化占位文字。
4. 封面下方排列最多四个半透明白色标签，标签宽度受限且不挤压后续内容。
5. 底部以细分隔线划分信息区，紧凑排列白色 Bilibili Logo、作者/BV 号和显著缩小的二维码；二维码保留必要的白色 quiet zone，扫描提示置于其下方。

## 输出约束

- 真实输出固定为 `1080 × 1080` PNG。
- 二维码、标题、作者、BVID、可选时间戳和标签继续使用现有会话数据。
- 不新增持久化字段，不改变分享 URL、时间戳和无封面降级契约。
- 所有页面数据仍按不可信文本绘制，标题最多两行并使用省略处理。
- 封面统一使用圆角裁切、阴影和压暗处理；封面主色不参与整体背景取色，避免不同视频导致海报风格漂移。

## 实现范围

海报布局和绘制集中在 `src/utils/bilibiliSharePoster.ts`；分享适配器只负责提供最多四个页面标签，Vue Dialog 复用现有二维码、Logo 资源、下载/复制动作及生命周期。验证继续使用现有最小契约测试、`pnpm lint` 和 `pnpm typecheck`，不执行构建命令。
