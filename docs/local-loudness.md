# 局部音量均衡

入口：设置 → Bilibili → 播放器 → 音量均衡。通过统一目标响度减少不同视频之间的音量差异，同时平滑视频内的大小声。默认关闭，推荐从 -18 LUFS、75% 强度开始。

启用时通过 B 站「设置 → 更多播放设置 → 音量均衡 → 关闭」组件处理原生均衡，不直接修改网站存储或私有 player 对象。确认关闭前不接管音频；启用期间阻止用户同时开启原生均衡。关闭插件功能后保持原生均衡关闭。若需要重新开启原生音效，先关闭本功能并刷新页面：浏览器不提供释放媒体元素音源所有权的接口。

视频控制栏的音量均衡按钮支持悬停调节开关、目标响度与强度，并显示当前视频的运行状态和最近 60 秒的均衡增益曲线（实际增益遥测，并非原始音频波形）。曲线最多保存 61 个采样点，换源、拖动进度或切换功能时清空，不缓存音频。全局设置不显示运行状态；可单独隐藏播放器按钮，隐藏不影响均衡开关。参数为全局偏好，运行状态按当前页面与视频源匹配。面板随播放器替换卸载，监听器、观察器与发现重试在隐藏、离页时清理。

## 算法

- 不依赖 B 站返回的整段响度数据。AudioWorklet 音频线程运行双声道 K-weighting 测量，使用 400 ms 和 3 s 滑动窗口，每 100 ms 更新一次控制目标。
- 使用 BS.1770 的声道能量与 K-weighting 计算方式；这是局部自动增益，不声称是完整的 EBU R128 节目响度归一化。默认目标 -18 LUFS，可调 -24～-14 LUFS。
- 将目标误差按强度折减；最大提升 6 dB、最大降低 18 dB。1 dB 死区减少抖动；下降最多 8 dB/s，回升最多 1.5 dB/s。低于 -50 LUFS 时冻结增益，避免持续提升静音或底噪。强度越高，对原有动态的改变越大。
- 独立的 5 ms 前瞻采样峰值限制器控制突发大声，输出采样峰值不超过 -1 dBFS，释放时间 80 ms。它不是过采样真峰值限制器，不保证编码后的 dBTP。
- 测量补偿媒体音量，避免自动增益抵消用户调节。静音、暂停、拖动进度时停止测量；换源或拖动进度清空统计和延迟缓冲。

## 音源与生命周期

在 document_start 使用弱引用映射记录原生创建的媒体音源。原生已有音源时，将 Worklet 插入其已有输出连接；关闭时还原连接，不关闭原生 AudioContext。自己接管的元素共享一个 AudioContext，关闭功能后保留最小原声旁路，不强行关闭导致失声。

- 每次绑定只有一个 Worklet 和一个 AbortController；解绑时恢复旁路、断开处理节点、发送 dispose、关闭 MessagePort、清空处理事件回调并撤销媒体事件监听。
- 固定长度类型数组存放响度窗口、延迟音频、单调队列，无随播放时长增长的音频缓存。
- 模块按 AudioContext 弱缓存；Blob URL 在 addModule 成功或失败后均释放。
- 异步加载使用代次检查，关闭功能、换视频或 pagehide 后不继续绑定过期任务。
- 自有音源仅在元素仍位于 DOM 时保持强引用；移除后断开输出并移出集合。弱缓存允许同一元素重新插入时复用音源。文档级观察器负责恢复必要旁路，不保留已移除元素。
- 无自有音源连接时暂停自有上下文；关闭功能停止发现定时器。页面离开时清理 DSP；BFCache 恢复时重新协调，真正退出时关闭自有上下文并撤销文档监听和原型补丁。
- 处理失败切回原声；不支持或无法确认跨域安全性的音源不接管。其他扩展若先于本插件占有音源，可能需要刷新或停用冲突音效。

## 验证范围

离线使用 44.1/48/96 kHz 的音调、静音、幅度切换和超限脉冲检查增益、用户音量比例及峰值边界。浏览器验证使用真实 B 站视频与开发扩展。长期播放、更多内容类型和 Firefox 仍需进一步听感与兼容验证；资源释放计数不能代替长期堆内存分析。
