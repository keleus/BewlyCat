# 顶栏常驻分区

在「设置 → Bewly 组件 → 顶栏」管理常驻分区。设置页默认只展示已添加的分区；展开「添加分区」后，可以搜索名称或标识，并在「全部」及五个主题分类之间切换。分类按钮不显示数量，搜索在当前分类内匹配；无结果时可切换到全部分类。

- 修改立即保存，新增项追加在末尾。「收起添加」可关闭添加面板，搜索内容和分类保持不变。
- 拖动手柄或使用前移、后移按钮调整优先顺序，拖动使用原始的 150ms 排序动画，按钮排序直接更新位置；系统要求减少动态效果时关闭拖动动画。
- 添加、移除、清空和排序均可通过「撤销上一步」逐步恢复，不设时间限制。切换设置子页面保留历史，关闭设置窗口后清空历史；已保存的配置不变。
- 其他标签页或导入操作改变分区选择时，清空旧撤销历史并提示；内容相同的存储回写不会清空历史。
- 隐藏常驻分区组件不会清空选择，可在同一区块重新启用。

## 空间与溢出

顶栏根据实际宽度分配空间，优先为搜索保留 320 CSS px，搜索最大宽度为 600 CSS px。分区按用户顺序显示，放不下的内容进入可点击的「+N」菜单；所有项折叠时显示「分区」。当 320px 搜索无法保持时，先折叠分区，再允许搜索缩至 240px。

必要控件与 240px 搜索无法同时放下时，次要操作收进右侧菜单、页面切换变为紧凑按钮，常驻分区保留图标入口。紧凑布局仍无法容纳输入框时，搜索也变为按钮，点击展开输入面板。取消了 1279px 以下直接隐藏常驻分区的规则。

分区菜单按内容自适应宽度（160–240 CSS px，并受视口安全宽度限制），优先与展开按钮右侧对齐，距视口至少 8px，长名称可换行，内容在菜单内滚动。分区菜单支持点击、Enter、Space 打开，Esc 关闭并返回入口；其中的链接沿用顶栏链接打开设置。菜单末尾的「管理常驻分区」直接定位对应设置。设置页的显示数量取自实际顶栏布局，顶栏未挂载时不提供推测数字。

## 维护约定

- `topBarPinnedChannels` 仍为有序的标识数组，兼容已有配置及导入导出。
- 尺寸预算和显示数量只保存在内存中；缩放、调整窗口不会重写选择。
- 无效或重复标识在展示时过滤；添加候选项仍来自既有分区常量。
- 搜索宽度及全折叠入口宽度使用 `--bew-top-bar-search-*`、`--bew-top-bar-pinned-collapsed-width` token。
- 顶栏父级负责空间预算，分区组件负责实际控件测量和前缀分配。展开比收起多要求 4px 余量，减少临界宽度抖动。

## 页面验收清单

以下为真实扩展页面的验收场景，不代表已经完成页面验证。运行页面操作前须取得明确授权，不使用模拟页面替代。

| 维度 | 场景 |
| --- | --- |
| 选择 | 0、1、5、15、47 项，重复及未知标识 |
| CSS 视口宽度 | 1920、1440、1280、1279、1024、768、640、320px，以及切换临界点 |
| 浏览器缩放 | 100%、125%、150%、175%、200%，同时记录实际 CSS 视口 |
| 状态 | 登录、未登录、搜索显隐、两种 Logo、触屏首页按钮、布局编辑、组件隐藏 |
| 显示 | 简繁中文、粤语、英文，深浅色、白色图标、毛玻璃开关 |
| 操作 | 连续添加、排序、移除、清空撤销、刷新恢复、菜单导航、Esc、Tab、缩放后的焦点恢复 |

通过标准：搜索和两侧不重叠；所有已选项始终可通过直接入口或菜单访问；菜单留在视口内且内部滚动；恢复宽度后恢复显示但不改变顺序；极窄状态仍能使用搜索、分区及右侧操作。
